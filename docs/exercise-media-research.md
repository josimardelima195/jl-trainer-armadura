# Catálogo de exercícios e mídia

## Biblioteca de imagens usada

O catálogo usa imagens reais do **Free Exercise DB**, uma base aberta publicada no GitHub sob Unlicense, com mais de 800 exercícios e imagens em duas posições por exercício. A aplicação usa URLs diretas somente para exercícios cujo nome e diretório foram conferidos.

Fonte: https://github.com/yuhonas/free-exercise-db

Exemplo de imagem: https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/Dumbbell_Bench_Press/0.jpg

Para novos exercícios, confirmar o diretório no `dist/exercises.json` antes de inserir o `image_path`. Não usar uma imagem de barra para um exercício com halteres.

A base maior `hasaneyldrm/exercises-dataset` contém 1.324 exercícios e metadados multilíngues, mas a documentação informa que a mídia é © Gym Visual e possui termos próprios. Ela não deve ser copiada para produção sem licença compatível ou compra de licença.

Fonte: https://github.com/hasaneyldrm/exercises-dataset

O GymVisual oferece GIFs, ilustrações e vídeos comerciais. É uma opção para uma futura biblioteca premium, mas deve ser licenciada antes de ser colocada no aplicativo.

Fonte: https://gymvisual.com/content/9-license

## Regras aplicadas

- Fortalecimento: base geral de 2–3 séries de 8–12 repetições, com progressão gradual e execução controlada.
- Emagrecimento/cardio: progressão por duração e intensidade, sem prometer que um exercício isolado causa perda de peso.
- Iniciantes: o aplicativo reduz o número sugerido de séries para 2.
- Pessoas com 60 anos ou mais: o aplicativo usa uma faixa inicial mais conservadora de 2 séries e 8–10 repetições quando o exercício admite repetições.
- Objetivos de emagrecimento/definição: a interface sugere 10–15 repetições para exercícios de força simples.
- Ganho de massa/bulking: a interface sugere 8–12 repetições.
- O peso e a altura entram no IMC e ajudam a evitar recomendações de alto impacto quando o IMC é elevado. Eles não determinam sozinhos uma carga segura; carga deve ser escolhida conforme técnica, experiência e, quando necessário, orientação profissional.
- Exercícios de natação, futsal e karaté precisam de adaptações específicas. Natação exige supervisão na água; kata e bunkai devem seguir a linhagem e o instrutor; futsal depende do espaço e dos equipamentos disponíveis.
